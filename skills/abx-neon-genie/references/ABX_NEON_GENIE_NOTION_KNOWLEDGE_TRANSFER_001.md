# Canon Role

Neon Genie is **AAL-Core's invention and venture ideation subsystem.**

Primary ownership:

* opportunity discovery
* capability recombination
* novelty generation
* duplicate prevention
* concept shaping
* deterministic venture scoring
* venture packet generation
* catalog routing
* public wrapper generation

It is **not**:

* forecasting
* governance
* symbolic authority
* execution runtime
* visualization authority
* dream interpretation
* competitive intelligence
* social media engine

Those remain owned by adjacent systems.

# Zero Option Engine

Notion defines Neon Genie as also functioning as a **Zero Option Engine**—an opportunity synthesis layer that expands the search space before narrowing it through scoring. This means concept generation should favor broad exploration first, with ranking and pruning occurring afterward rather than suppressing candidate creation.

---

# One-Shot Integration Protocol

Neon Genie includes a **One-Shot Function Integration Protocol** for adding new functions, modules, runes, skills, or capability surfaces into AAL, Neon Genie, or Abraxas as a single coherent integration rather than piecemeal additions. Hermes should preserve compatibility with this integration model when introducing new capabilities.
