# NOCTIS delivery contract

Canonical runner: scripts/research/run_noctis_dream.py (full checkout).
Nested operator_packet schema: contracts/noctis/dream_operator_packet.v0.schema.json.
This runner remains a thin stub/motif adapter, not a full dream engine. Require
STUB_EXECUTED (or honest NOT_COMPUTABLE), no runtime/promotion/forecast/medical
authority, memory_candidate_only true, and unvalidated real core functions
explicitly listed. Never infer a live pipeline from successful schema parsing.

PRIVATE input must not appear verbatim in the operator packet: no
narrative_excerpt, narrative_excerpt_allowed=false; only hash and bounded IR
motifs. SYSTEM fixtures are explicit PUBLIC_SYNTHETIC and must not be described
as user reports. Do not copy private raw narratives into external handoffs.
The SKILL.md fixture command checks the nested schema and authority locks; the
referenced pytest suite additionally checks private input suppression, empty
input, determinism and missing-file rejection. Paths in artifacts are logical
references, not proof of existing downstream artifact files.
