# NOCTIS Hard Boundaries

## Privacy
- Preserve `privacy_tier`.
- Route compressed motif packets by default for downstream.
- Never place raw PRIVATE narrative into public artifacts, test fixtures, or un-gated Oracle.

## Medical / Therapy / Diagnostic
- Explicitly disabled in all outputs and authority badges.
- Framing limited to: symbolic interpretation, reflective hypothesis, motif observation, creative/journaling prompt.

## Memory
- Only `MemoryWriteCandidate`, `SymbolicContinuityLedgerEntry`, or equivalent candidate receipts.
- `direct_write_allowed: false`
- `operator_review_required: true`
- Route candidates through YGGDRASIL manager + review surface.

## Oracle / SHADOW
- Compressed motifs, tension clusters, resonance hints only.
- Lane: SHADOW_SYMBOLIC.
- No raw private narrative, no forecast weights, no Brier, no promotion decisions.

## Forecast
- Dream-derived material may **only** produce:
  - PROBE_READY
  - CANDIDATE_ONLY
  - OBSERVE_ONLY
- Must pass probe → non-dream evidence → simulation → validation → governance review before any forecast influence.

## YGGDRASIL / Canon
- Candidate surfaces only. No direct mutation by this skill.
- Use `abx-runes-yggdrasil-manager` for any route/rune registration.

## System Dream Labeling
- `source: SYSTEM`
- `synthetic: true`
- Explicit constraint profile and seed required.
- Content classified SPECULATIVE unless directly sourced components are labeled separately.

All violations → fail closed.
