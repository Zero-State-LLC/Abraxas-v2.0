# Source rotation (anti-grip)

When foraging modular synth, AI tooling, or any vendor-dense domain, **force rotation**:

1. Official primary (docs, SEC, standards body)
2. Independent secondary (trade press, academic)
3. Code / registry (GitHub, package index)
4. Market / social (optional, weak)
5. Local repo / prior receipts

Stop when:

- All `must_answer` resolved or marked NOT_COMPUTABLE, or
- Last 2 sources added no new OBSERVED claims

Log skipped domains in brief ("did not pull Reddit; noise budget").
