# NOT_COMPUTABLE Conditions (ABX.EsotericIntelligence.v0.1)

Return NOT_COMPUTABLE (or CONFLICTED) when:
- Required source unavailable
- Attribution has no identifiable provenance
- Astrology calc missing birth/event data, ephemeris, or engine
- Deterministic deck draw missing seed/recorded state (when reproducibility required)
- Numeric system unspecified
- Symbol has multiple unresolved traditions
- Cross-tradition mapping lacks functional evidence
- Quotation unverifiable
- Ritual lineage/grade unsourced
- Input too incomplete to separate observation from interpretation
- Evidence anchors cannot attach
- Request requires unsupported forecast/execution/canon authority

Never force an answer. Emit reason + alternatives where possible.
