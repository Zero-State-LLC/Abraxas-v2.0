# Symbolic Metabolism (ALife Adapter)

Ritual and transformation as bounded metabolic processes.

## Mapping
- Intake / invocation → environmental nutrient
- Purification / boundary → membrane / filtering
- Offering → nutrient input
- Ordeal / transformation → metabolic reaction
- Integration / closure → phenotype stabilization

## Packet (ABX.SymbolicMetabolismPacket.v1 — minimal)
Fields include: input_primitives, admitted_symbols, reaction_sequence, catalysts, inhibitors, transformation_products, unresolved_residues, toxic_byproducts (TRADITION_FLATTENING, FALSE_ATTRIBUTION, etc.), output_phenotype, closure_status, provenance, execution_claimed: false.

Toxic byproducts are tracked explicitly. Closure does not imply execution.
