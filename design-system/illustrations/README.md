# Illustration language

Technical, evidence-oriented diagrams only.

## Rules (from docs/media, elevated)

- Observable architecture only — no fake runtimes.
- No robots, brains, generic AI imagery.
- Shared node/edge language across atlas diagrams.
- Lane labels + evidence captions over marketing copy.
- Route/Rune binding: `FORMALIZED_ADVISORY` + advisory border token.
- Belief graph / unimplemented: `NOT_COMPUTABLE` styling — never “implemented” cyan.

## Surface tier borders

| Tier | Token | Use |
|------|-------|-----|
| 1 routing/runtime | `--abx-tier-1` | Runtime maps, Yggdrasil |
| 2 governance/continuity | `--abx-tier-2` | Continuity spine, promotion |
| 3 research/projection | `--abx-tier-3` | AAL projection, research |
| Advisory | `--abx-tier-advisory` | Shadow / formalized advisory |
