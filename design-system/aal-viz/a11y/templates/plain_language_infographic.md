# Plain-language infographic template

1. **What this shows** — one sentence, projection-only.
2. **What is observed** — bullets from source artifacts only.
3. **What is inferred** — explicitly labeled INFERRED.
4. **What is blocked** — NOT_COMPUTABLE / FAIL_CLOSED with reason code.
5. **What to do next** — operator action or “no action; held”.
6. **Sources** — artifact ids / paths.
