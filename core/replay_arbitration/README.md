# ReplayTemporalArbitration.v1 Canonical Layer

Deterministic temporal arbitration over replay lineages that preserves divergent ancestry without rewriting, normalizing, or collapsing replay history.

This layer is non-executing and non-mutating: no live execution, mutation authorization, ledger rewriting, replay-history normalization, routing changes, adapter activation, global runtime activation, or subsystem rewiring.

Future convergence: this canonical arbitration layer coexists with any broader governance/arbitration modules until interfaces converge.
